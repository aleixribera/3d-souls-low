# Combat Arena 3D

A small Souls-like 3D duel in a single HTML file (Three.js from a CDN, no build step).

## Play

- **Online:** open the GitHub Pages link for this repo (Settings → Pages).
- **Locally:** download `combat-arena-3d.html` and open it in a browser. It needs internet access once to load Three.js.

Keyboard and mouse only; there are no touch controls.

## Controls

| Action | Keys |
|---|---|
| Move | W A S D / Arrow keys |
| Jump | Space |
| Roll | Shift |
| Light attack | J / Left mouse |
| Heavy attack | K / quick right-click |
| Block (hold) | L / Ctrl |
| Parry | E |
| Lock-on | Q |
| Orbit camera | Hold right mouse + drag, wheel zooms |
| Shoulder camera | V |
| Reset fight | R |
| Menu | Escape |
| Help / hitboxes | F1 |
